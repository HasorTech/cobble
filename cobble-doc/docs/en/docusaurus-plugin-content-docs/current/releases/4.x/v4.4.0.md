# v4.4.0 (2022-06-08)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.4.0</version>
</dependency>
```

## Changes

- Added
  - `Proxy` in `cobble-dynamic` supports existing objects and abstract classes, and can supply method implementations.
  - Dynamic proxies support `@Aop` annotations again.
- Improved
  - The dynamic proxy entry points follow the JDK `Proxy` calling style.

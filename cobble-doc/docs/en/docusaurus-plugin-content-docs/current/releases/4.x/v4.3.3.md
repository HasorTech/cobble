# v4.3.3 (2022-04-05)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.3</version>
</dependency>
```

## Changes

- Added
  - Property access functions in `BeanUtils` now support maps.
  - `IOUtils.closeQuietly(...)` accepts `AutoCloseable`, and `StringUtils` converts between underscore-separated and camel-case names.
- Improved
  - Improved `HexUtils.bytes2hex(...)`.

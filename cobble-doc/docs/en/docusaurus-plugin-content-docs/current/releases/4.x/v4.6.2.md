# v4.6.2 (2024-01-21)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.6.2</version>
</dependency>
```

## Changes

- Fixed
  - Fixed synchronization between `BasicFuture` completion, failure, or cancellation and listener registration or waiting threads.
  - Fixed null class-loader handling in `ThreadUtils` and added a `Callable` overload.

## Upgrade notes

- Networking and byte-buffer modules moved to the independent Neta project. Logging utilities moved into `cobble-lang`.

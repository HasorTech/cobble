# v4.7.1 (2025-06-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.7.1</version>
</dependency>
```

## Changes

- Added
  - Added the `Tuple` utility, collection grouping, and readable file-size formatting.
- Improved
  - String reads use a character buffer, with an `IOUtils.readToString(...)` overload that limits the read length.
- Fixed
  - Fixed resources added after an internationalization lookup and improved locale matching on newer JDKs.

## Upgrade notes

- Removed string utilities that depended on `sun.nio.cs`.

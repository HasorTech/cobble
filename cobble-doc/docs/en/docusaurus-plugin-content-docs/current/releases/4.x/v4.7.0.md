# v4.7.0 (2025-02-12)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.7.0</version>
</dependency>
```

## Changes

- Added
  - Added `Annotations` and `ByteCodeTools` to construct annotation data and work with bytecode.
  - Resource lookup in `ResourcesUtils` accepts inputs prefixed with `file://` or `classpath://`.
- Fixed
  - Fixed `LinkedCaseInsensitiveMap.getOrDefault(...)` and issues loading JAR resources.
- Improved
  - Reworked the `ISOLATION` and `MERGE` class-loader strategies.

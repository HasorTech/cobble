# v4.5.4 (2023-07-24)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.5.4</version>
</dependency>
```

## Changes

- Added
  - Added `I18nUtils`, directory traversal with `FileUtils.walk(...)`, and collection-to-tree conversion utilities.
- Fixed
  - Fixed recursive `classpath:` URL lookup and date formatting that dropped a zero-minute time-zone offset.

## Upgrade notes

- `StreamByteBuf.loadData(...)` became `fetch()`. The buffer window determines how much data it reads.

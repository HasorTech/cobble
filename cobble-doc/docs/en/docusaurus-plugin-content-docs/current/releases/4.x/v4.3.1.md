# v4.3.1 (2022-03-17)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.1</version>
</dependency>
```

## Changes

- Added
  - Settings resolve environment variables, and `cobble-lang` adds `GenericTokenParser` and `SystemUtils`.
- Improved
  - Separated `LoaderClassLoader` and `ClassFinder` so they can be composed for class isolation.

## Upgrade notes

- Logging moved into `cobble-lang`, and thread and future utilities were consolidated under `concurrent`.

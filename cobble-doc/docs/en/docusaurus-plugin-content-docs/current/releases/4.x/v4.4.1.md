# v4.4.1 (2022-07-31)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.4.1</version>
</dependency>
```

## Changes

- Added
  - Added `Ratio` for weighted random selection, with `clearRatio()` to reset it.
  - Added string splitting on multiple delimiters and reading files from the end. Collection emptiness checks accept the broader `Collection` type.
- Fixed
  - Fixed SLF4J INFO logging that printed the class name in place of the message.

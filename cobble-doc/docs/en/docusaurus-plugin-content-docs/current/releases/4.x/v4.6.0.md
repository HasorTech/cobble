# v4.6.0 (2023-09-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.6.0</version>
</dependency>
```

## Changes

- Added
  - Added the Java AIO-based `cobble-net` module and asynchronous `BasicFuture` listeners through an interface extending the JDK `Future`.
  - Byte buffers add concurrent wait methods and unsigned 32-bit writes.
- Fixed
  - Corrected internationalization resource loading order and added `@I18nResource` for declaring resources on classes.

## Upgrade notes

- Settings refresh was consolidated in `BasicSettings`, and `IOSettings` was removed.

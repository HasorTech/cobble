# v4.5.0 (2022-12-30)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.5.0</version>
</dependency>
```

## Changes

- Added
  - Added `cobble-bytebuf` with byte buffers, adapters, and allocator APIs.
  - `CollectionUtils` adds `asList(...)` and `asMap(...)`, and `RandomUtils` gains additional utilities.
- Fixed
  - Fixed classpath scanning for paths with special characters and corrected buffer index handling.

# v4.3.0 (2021-12-06)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.0</version>
</dependency>
```

## Changes

- Overview
  - This tag contains `cobble-lang`, `cobble-dynamic`, `cobble-loader`, `cobble-settings`, and the `cobble-all` aggregate.
  - Provides ASM-based proxies, resource scanning and loader composition, and unified access to Properties, XML, and YAML settings.
- Added
  - Added `StringEscapeUtils` and made the property-write converter configurable in `BeanMap`.

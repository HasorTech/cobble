# v4.8.0 (2025-09-19)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.8.0</version>
</dependency>
```

## Changes

- Added
  - Added module support for JDK 9 and later and compatibility with JDK 17.
  - Added a small byte-buffer utility derived from Neta.
- Fixed
  - Restored `escapeEncode(...)` and `escapeDecode(...)` using public APIs.

## Upgrade notes

- The project builds on JDK 9 or later and retains Java 8 as the standard compilation target.

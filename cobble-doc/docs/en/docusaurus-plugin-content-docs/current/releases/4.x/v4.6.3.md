# v4.6.3 (2024-04-05)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.6.3</version>
</dependency>
```

## Changes

- Added
  - Resource scans can exclude roots with a `Predicate<URI>`, and resource loaders add an API for querying resource sizes.
  - `SingletonScope.clean()` clears cached singletons.
- Fixed
  - Fixed `ImportResourceLoader` returning a resource stream that was already closed.

## Upgrade notes

- Removed the experimental sandbox code. The loader continues to provide class-loader composition.

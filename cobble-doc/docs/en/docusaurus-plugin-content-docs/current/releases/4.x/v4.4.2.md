# v4.4.2 (2022-09-29)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.4.2</version>
</dependency>
```

## Changes

- Added
  - Classpath scanning supports JDK 9 and later, and string trimming accepts a chosen character.
- Fixed
  - Fixed property functions returning empty values, mixed-case enum lookup, and incorrect string trimming.
- Improved
  - Adding settings without a namespace now uses the default namespace.

## Upgrade notes

- Rename references to `HexUtils` to `HexadecimalUtils`.

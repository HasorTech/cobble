# v4.3.4 (2022-05-23)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.4</version>
</dependency>
```

## Changes

- Added
  - `Settings` adds `evalSetting(...)`, and resource loading supports protocol handlers registered through `java.protocol.handler.pkgs`.
- Fixed
  - Corrected class loading and isolation in `ResourceLoader`.

## Upgrade notes

- `cobble-loader` can be used without `cobble-lang`. This release removes Cobble's `@Aop` annotation.

# v5.0.1 (2026-07-14)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.1</version>
</dependency>
```

## Changes

- Improved
  - `CobbleClassLoader` distinguishes parent-first and local-first loading. Classes matching the inclusion rules try local resources first and then fall back to the parent loader.
- Fixed
  - Fixed default internationalization keys failing to propagate updates through the inheritance hierarchy.

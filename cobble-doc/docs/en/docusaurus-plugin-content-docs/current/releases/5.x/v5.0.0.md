# v5.0.0 (2026-06-20)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.0</version>
</dependency>
```

## Changes

- Added
  - Added shutdown-hook subscriptions and registered the JAR URL handler through `URLStreamHandlerProvider`.
- Fixed
  - Improved closing of JAR, import, and composite resource loaders and fixed object proxies on JDK 21.

## Upgrade notes

- The compilation target is Java 17. Modules use `Automatic-Module-Name`, and resource loaders implement `Closeable`.

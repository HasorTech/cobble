# v5.0.5 (2026-11-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.5</version>
</dependency>
```

## Changes

- Added
  - Added `JsseUtils` for TLS endpoint certificate identity checks and initialization of key stores, `KeyManagerFactory`, and `TrustManagerFactory`.
  - Added `NetworkUtils.toDNSAscii(...)` and `toDNSUnicode(...)` to convert between internationalized domain names and Punycode.
- Fixed
  - Preserved encoded classpath resource URLs and custom URL handlers during resource loading.
  - Aligned `StringUtils.equalsIgnoreCase(...)` with JDK behavior for locale-independent Unicode comparison.
  - Fixed lost shutdown callbacks during concurrent registration and removal.
  - Fixed missed wakeups after `BasicFuture` completion, failure, or cancellation and corrected sub-millisecond timeout handling.
- Improved
  - Migrated tests to JUnit Jupiter.
  - Added Chinese and English documentation sites.

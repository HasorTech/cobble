# v5.0.4 (2026-10-05)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.4</version>
</dependency>
```

## Changes

- Added
  - Added `CursorArrayList` for cursor-based consumption and compaction of consumed entries at a configurable threshold.
- Fixed
  - Fixed concurrent map access during `I18nUtils` initialization.

## Upgrade notes

- Object pools are independent generic instances, and global type registration was removed. Both cache levels support count or weight limits.

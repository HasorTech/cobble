Cobble is a modular Java toolkit for common utilities, dynamic proxies, resource discovery and loading, and configuration reading. Applications and frameworks can use each module independently.

| Task | Module |
| --- | --- |
| Work with strings, collections, and type conversion | [cobble-lang](modules.md#cobble-lang) |
| Generate a proxy or enhance an existing object | [cobble-dynamic](modules.md#cobble-dynamic) |
| Discover and load project resources | [cobble-loader](modules.md#cobble-loader) |
| Read configuration through a common interface | [cobble-settings](modules.md#cobble-settings) |

The current source builds with Java 17. Each module uses the Maven group ID `net.hasor` and the artifact ID shown in the table. Choose the modules you need.

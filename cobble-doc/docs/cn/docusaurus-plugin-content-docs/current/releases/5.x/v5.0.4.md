# v5.0.4 (2026-10-05)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.4</version>
</dependency>
```

## 更新内容

- 新增
  - 新增 `CursorArrayList`，支持通过游标消费列表并按阈值压缩已消费区间。
- 修复
  - 修复 `I18nUtils` 并发初始化时的映射访问问题。

## 升级说明

- 对象池改为独立泛型实例，移除全局类型注册。两级缓存支持按数量或权重限制容量。

# v5.0.5 (2026-11-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.5</version>
</dependency>
```

## 更新内容

- 新增
  - 新增 `JsseUtils`，支持 TLS 端点证书身份校验及密钥库、`KeyManagerFactory` 和 `TrustManagerFactory` 初始化。
  - 新增 `NetworkUtils.toDNSAscii(...)` 和 `toDNSUnicode(...)`，支持国际化域名与 Punycode 的双向转换。
- 修复
  - 修复类路径资源 URL 的编码和自定义 URL 处理器在加载过程中丢失的问题。
  - 修复 `StringUtils.equalsIgnoreCase(...)` 受默认语言环境和 Unicode 大小写扩展影响的问题。
  - 修复并发注册与注销关闭钩子时可能丢失回调的问题。
  - 修复 `BasicFuture` 在完成、失败或取消后可能无法唤醒等待线程的问题，并修正亚毫秒超时等待。
- 优化
  - 测试迁移到 JUnit Jupiter。
  - 新增中英文文档站。

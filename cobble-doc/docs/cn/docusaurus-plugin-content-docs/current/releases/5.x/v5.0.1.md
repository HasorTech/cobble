# v5.0.1 (2026-07-14)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.1</version>
</dependency>
```

## 更新内容

- 优化
  - `CobbleClassLoader` 区分父优先和本地优先策略。命中包含规则时先从本地资源加载，再回退到父加载器。
- 修复
  - 修复默认国际化键更新后没有沿继承关系传播的问题。

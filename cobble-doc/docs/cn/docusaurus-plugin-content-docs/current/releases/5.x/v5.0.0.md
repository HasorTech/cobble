# v5.0.0 (2026-06-20)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>5.0.0</version>
</dependency>
```

## 更新内容

- 新增
  - 新增关闭钩子订阅机制，JAR URL 处理器通过 `URLStreamHandlerProvider` 注册。
- 修复
  - 完善 JAR、导入和组合资源加载器的关闭行为，修复 JDK 21 下的对象代理问题。

## 升级说明

- 编译目标切换到 Java 17。模块名通过 `Automatic-Module-Name` 声明，资源加载器实现 `Closeable`。

# v4.6.2 (2024-01-21)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.6.2</version>
</dependency>
```

## 更新内容

- 修复
  - 修复 `BasicFuture` 完成、失败、取消与监听器注册和等待线程之间的同步问题。
  - 修复 `ThreadUtils` 使用空类加载器的问题，并增加 `Callable` 形式。

## 升级说明

- 网络与字节缓冲区相关模块移至独立的 Neta 项目，日志工具并入 `cobble-lang`。

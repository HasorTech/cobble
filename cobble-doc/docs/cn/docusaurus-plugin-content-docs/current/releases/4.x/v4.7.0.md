# v4.7.0 (2025-02-12)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.7.0</version>
</dependency>
```

## 更新内容

- 新增
  - 新增 `Annotations` 和 `ByteCodeTools`，支持构造注解信息及字节码处理。
  - `ResourcesUtils` 的资源查找方法支持带 `file://` 或 `classpath://` 前缀的输入。
- 修复
  - 修复 `LinkedCaseInsensitiveMap.getOrDefault(...)` 无效的问题及 JAR 资源加载问题。
- 优化
  - 调整类加载器的 `ISOLATION` 和 `MERGE` 策略。

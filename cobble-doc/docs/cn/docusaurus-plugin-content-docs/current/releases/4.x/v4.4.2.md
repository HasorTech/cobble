# v4.4.2 (2022-09-29)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.4.2</version>
</dependency>
```

## 更新内容

- 新增
  - 类路径扫描兼容 JDK 9 及以上版本，新增指定字符的字符串裁剪方法。
- 修复
  - 修复属性函数返回空值、混合大小写枚举识别错误及字符串裁剪异常。
- 优化
  - 添加配置时允许省略命名空间，省略时使用默认命名空间。

## 升级说明

- `HexUtils` 更名为 `HexadecimalUtils`。

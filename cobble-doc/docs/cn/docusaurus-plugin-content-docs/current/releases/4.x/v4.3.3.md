# v4.3.3 (2022-04-05)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.3</version>
</dependency>
```

## 更新内容

- 新增
  - `BeanUtils` 的属性访问函数支持 Map。
  - `IOUtils.closeQuietly(...)` 支持 `AutoCloseable`，`StringUtils` 提供下划线与驼峰命名转换。
- 优化
  - 优化 `HexUtils.bytes2hex(...)`。

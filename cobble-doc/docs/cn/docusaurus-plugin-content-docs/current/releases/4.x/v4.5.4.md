# v4.5.4 (2023-07-24)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.5.4</version>
</dependency>
```

## 更新内容

- 新增
  - 新增 `I18nUtils`、目录遍历 `FileUtils.walk(...)`，以及集合与树结构的转换方法。
- 修复
  - 修复 `classpath:` URL 查找递归及日期格式化遗漏零时区分钟的问题。

## 升级说明

- `StreamByteBuf.loadData(...)` 改为 `fetch()`，读取量由缓冲区窗口决定。

# v4.6.3 (2024-04-05)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.6.3</version>
</dependency>
```

## 更新内容

- 新增
  - 资源扫描可以用 `Predicate<URI>` 排除资源根，资源加载器新增查询资源大小的接口。
  - `SingletonScope.clean()` 支持清除单例缓存。
- 修复
  - 修复 `ImportResourceLoader` 返回已关闭资源流的问题。

## 升级说明

- 移除实验性沙箱代码，加载器继续提供类加载器编排。

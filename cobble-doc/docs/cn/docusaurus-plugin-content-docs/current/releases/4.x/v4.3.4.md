# v4.3.4 (2022-05-23)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.4</version>
</dependency>
```

## 更新内容

- 新增
  - `Settings` 增加 `evalSetting(...)`，资源加载支持通过 `java.protocol.handler.pkgs` 注册协议处理器。
- 修复
  - 修正 `ResourceLoader` 的类加载与隔离行为。

## 升级说明

- `cobble-loader` 可脱离 `cobble-lang` 使用，本版本移除了 Cobble 中的 `@Aop` 注解。

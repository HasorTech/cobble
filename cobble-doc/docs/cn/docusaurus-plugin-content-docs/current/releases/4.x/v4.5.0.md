# v4.5.0 (2022-12-30)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.5.0</version>
</dependency>
```

## 更新内容

- 新增
  - 新增 `cobble-bytebuf` 模块，提供字节缓冲区、适配器和分配接口。
  - `CollectionUtils` 增加 `asList(...)`、`asMap(...)`，并扩展 `RandomUtils`。
- 修复
  - 修复类路径扫描误过滤特殊字符及部分缓冲区索引问题。

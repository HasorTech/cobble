# v4.7.1 (2025-06-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.7.1</version>
</dependency>
```

## 更新内容

- 新增
  - 新增元组工具 `Tuple`、集合分组方法及文件大小格式化方法。
- 优化
  - 改用字符缓冲读取字符串，并增加可限制读取长度的 `IOUtils.readToString(...)` 重载。
- 修复
  - 修复国际化查询后追加的资源未生效问题，并改善高版本 JDK 下的 Locale 匹配。

## 升级说明

- 移除依赖 `sun.nio.cs` 的字符串工具方法。

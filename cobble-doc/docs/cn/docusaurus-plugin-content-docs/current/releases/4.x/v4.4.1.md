# v4.4.1 (2022-07-31)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.4.1</version>
</dependency>
```

## 更新内容

- 新增
  - 新增按权重随机选择的 `Ratio`，可通过 `clearRatio()` 重置。
  - 新增多分隔字符切分和从文件末尾读取的方法，集合判空方法接受更通用的 `Collection`。
- 修复
  - 修复 SLF4J INFO 日志误输出类名的问题。

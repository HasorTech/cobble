# v4.4.0 (2022-06-08)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.4.0</version>
</dependency>
```

## 更新内容

- 新增
  - `cobble-dynamic` 的 `Proxy` 支持代理现有对象和抽象类，并提供方法实现能力。
  - 动态代理重新支持 `@Aop` 注解。
- 优化
  - 动态代理入口按 JDK `Proxy` 的调用风格调整。

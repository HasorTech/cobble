# v4.3.1 (2022-03-17)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.1</version>
</dependency>
```

## 更新内容

- 新增
  - 配置读取支持解析环境变量，`cobble-lang` 新增 `GenericTokenParser` 和 `SystemUtils`。
- 优化
  - 将 `LoaderClassLoader` 与 `ClassFinder` 拆为独立组件，用组合方式实现类隔离。

## 升级说明

- 日志封装并入 `cobble-lang`，线程及 Future 工具整理到 `concurrent` 包。

# v4.6.0 (2023-09-27)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.6.0</version>
</dependency>
```

## 更新内容

- 新增
  - 新增基于 Java AIO 的 `cobble-net`，`BasicFuture` 通过扩展 JDK `Future` 的接口支持异步监听器。
  - 字节缓冲区新增并发等待方法和无符号 32 位写入。
- 修复
  - 修复国际化资源的加载顺序，新增 `@I18nResource` 以声明类上的资源。

## 升级说明

- 配置刷新调整到 `BasicSettings`，移除 `IOSettings`。

# v4.8.0 (2025-09-19)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.8.0</version>
</dependency>
```

## 更新内容

- 新增
  - 增加 JDK 9 及以上版本的模块化支持，并适配 JDK 17。
  - 从 Neta 提炼简化版字节缓冲工具。
- 修复
  - 恢复 `escapeEncode(...)` 与 `escapeDecode(...)`，实现改用公开 API。

## 升级说明

- 项目构建使用 JDK 9 或以上版本，常规编译目标仍为 Java 8。

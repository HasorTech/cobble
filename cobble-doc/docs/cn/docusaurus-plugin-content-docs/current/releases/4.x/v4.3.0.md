# v4.3.0 (2021-12-06)

```xml
<dependency>
    <groupId>net.hasor</groupId>
    <artifactId>cobble-all</artifactId>
    <version>4.3.0</version>
</dependency>
```

## 更新内容

- 概要
  - 这个标签包含 `cobble-lang`、`cobble-dynamic`、`cobble-loader`、`cobble-settings` 和聚合模块 `cobble-all`。
  - 提供 ASM 动态代理、资源扫描与加载器编排，以及 Properties、XML 和 YAML 的统一配置读取。
- 新增
  - 新增 `StringEscapeUtils`，`BeanMap` 支持配置属性写入时使用的类型转换器。
